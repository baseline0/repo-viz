# Contributing to repo-viz

repo-viz produces a versioned static graph artifact, renders it in a Svelte canvas viewer, and evaluates configurable indicator slots. Keep those boundaries intact: the snapshot is derived, evaluators are pure, and dispatch is human-approved.

## Setup

    uv sync --dev
    just test
    just check
    just --list

The frontend needs Node/npm only to build: `just frontend-check`, `just frontend-build`. Built assets are git-ignored.

## Test layout

| Directory | Tier | Rules |
|---|---|---|
| `tests/unit/` | unit | Hermetic: no filesystem, no network, no GPU, no sibling repos. |
| `tests/integration/` | integration | May use `tmp_path`, git, and the Typer CLI; no network or GPU. |
| `tests/conftest.py` | fixtures | Shared fixtures and folder-derived markers; do not hand-mark tier. |

Shared fixtures live in `tests/conftest.py` and data in `tests/fixtures/`. Markers come from the top-level test folder, so never write `@pytest.mark.unit` or `@pytest.mark.integration` in a test file.

Run `just test` for the hermetic unit gate; `just test-integration` for the local integration tier.

## Changes

- Spec first: dataclasses or enums with invariants, then valid and invalid tests. Add a `## Specification Map` to the module docstring and delete redundant prose last.
- Document headers are required for root governance and `docs/**` files: `agentic-id`, `doc-class`, `lifecycle`, `authority` before the H1.
- Every CLI uses Typer with a `--json` option (`repo_viz.output.JsonOption`); argparse is banned. Keep command bodies thin: parse options, call a pure function, then put JSON-serializable data on `CommandOutput.data`. Generated just recipes and FastAPI routes will read the same Typer app.
- Indicators are config entries in `config/indicators.toml` bound to dotted `module:function` evaluators. An evaluator receives `(node, context)` and returns `(state, value, evidence)`. Missing producer data yields `na`, never a pass. Thresholds are context-specific and live in config, not in code defaults alone.

## Derived artifacts

`graph.json`, `indicators.json`, and `src/repo_viz/static/` are regenerated by `just analyze`, `just indicators`, and `just frontend-build`. Never hand-edit or commit them.

## Git workflow

Work on an `agent/<task>` workspace branch created through fleet-ops workspace commands. Stage exact files, then commit with `just commit` (never raw `git commit`) and let the owner push. After a push, verify `HEAD == origin/main` and remove only your own merged workspace with `just workspace-remove <task>`.

Cross-repo changes (fleet-coordination registry, charters, workflow matrices) and publishing or permission changes require explicit owner approval.
